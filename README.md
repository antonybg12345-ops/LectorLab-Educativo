## Demo LectorLab 2.0

Demostración de interfaces docente y estudiante con datos ficticios. El archivo index.html es autocontenido y funciona sin instalar Node.js.

Permite ensayar grupos, borradores, evidencias, publicación, asignaciones, preguntas de varios tipos, entrega, rúbrica, devolución y CSV. El botón «Cargar ejemplo para exponer» prepara un recorrido ficticio para presentar la revisión sin escribir todas las respuestas.

Los datos permanecen en memoria de una sola pestaña y se reinician al recargar. El selector de vista no autentica. No utiliza cuentas reales, IA, Google Sheets, extracción documental ni una base central. Todo el contenido del HTML es público; no introducir datos personales ni contraseñas reales.

Para GitHub Pages, usar esta rama y /(root). No contiene el servidor, credenciales ni datos de estudiantes.
