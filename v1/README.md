# LectorLab — primera versión en GitHub Pages

Conserva el diseño, la lectura de El almohadón de pluma, las siete etapas, seis preguntas de primer intento en la pestaña, hipótesis, producción final, cierre orientativo, insignia y referencias de la versión original. Utiliza las correcciones verificadas de Etapa A.

Esta publicación estática no autentica ni guarda resultados en un servidor. Las respuestas se pierden al recargar. No es una calificación académica verificada. El tutor usa una guía fija explícitamente sin IA; no se fingen conversaciones ni se incluyen claves de API.

Excel se genera realmente en el navegador con las mismas tres hojas de Etapa A: Resumen, Respuestas y LectorLab. Se conserva validación de datos y cómputo del indicador desde respuestas; no hay verificación de identidad ni autoría. Se usan celdas de texto para los escritos.

Se mantienen las tres referencias originales a imágenes de Wikimedia. Si no cargan, se conserva su espacio con un aviso; no se sustituyen silenciosamente por ilustraciones nuevas. Las fuentes bibliográficas se abren solo cuando el usuario las consulta.

Biblioteca redistribuida: ExcelJS 4.4.0 (MIT). Ver vendor/ExcelJS-LICENSE.txt; el bundle conserva su cabecera de licencia.

La demo 2.0 sigue en la raíz del sitio y no se modifica.
